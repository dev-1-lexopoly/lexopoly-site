Frequently Asked Questions

How does Lex differ from using MailMan directly?

MailMan is the infrastructure — the API and dashboard for sending physical mail. Lex is an AI assistant who uses that same API on your behalf through natural conversation. Instead of filling out forms or writing API calls, you just tell Lex what you need.

Can I use Lex without MailMan?

Lex is built on top of MailMan, so a MailMan account is required. When you talk to Lex, he handles the MailMan interactions for you — you don’t need to use the MailMan dashboard separately.

What happens if Lex encounters an issue?

Lex has built-in smart escalation. If he encounters something outside his capabilities — like an unusual mailing requirement or a system issue — he’ll escalate to a human operator with full context so nothing falls through the cracks.

Does Lex have access to my firm’s data?

Lex only accesses what’s needed to complete your mailing requests: document content, recipient addresses, and mailing preferences. He operates within the same privacy architecture as the rest of the Lexopoly platform.
